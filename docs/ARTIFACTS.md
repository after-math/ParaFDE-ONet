# Data and weights

Synthetic reference trajectories are generated by the experiment solvers. The source release includes equations, seeds, sampling rules and scientific configurations, plus compact archived paper results. It does not include full training arrays or pretrained neural-network weights.

## Formal runs

The three benchmark training pipelines write:

```text
outputs/<run>/full/
├── resolved_config.json
├── dataset/test.npz
└── methods/<model>/seed_<seed>/best_model.pt
```

After a full run, stage its inputs for the benchmarks:

```bash
python scripts/prepare_artifacts.py competition with_sensitivity outputs/competition
python scripts/prepare_artifacts.py sei with_sensitivity outputs/sei
python scripts/prepare_artifacts.py nicholson with_sensitivity outputs/nicholson
```

This copies the test split, resolved configuration and available best checkpoints into `artifacts/<system>/<variant>/`. It refuses smoke runs, checks the required paired seed, records checksums, and refuses to overwrite an existing artifact directory. Large training arrays are not copied. The generated `artifacts/` directory is ignored by Git.

The inverse benchmark expects the ParaFDEONet checkpoints at seeds 20261005, 20260903 and 20260901 for competition, SEI and Nicholson respectively. Use `--checkpoint` to select a different checkpoint explicitly. The feature-reuse benchmark needs all three Nicholson architectures at seed 20260905.

For the Jacobian ablation, also train and stage the paired no-sensitivity variants:

| System | Variant directory |
| --- | --- |
| Competition | `experiments/competition/four_methods_normalized_no_sensitivity_5seeds/` |
| SEI | `experiments/sei/stratified_history_balanced_normalized_no_sensitivity/` |
| Nicholson | `experiments/nicholson/` |

Their pipeline is `code/scripts/pipeline.py`. Pass `--config`, `--output-dir`, `--devices`, `--cpus`, `--wandb-mode disabled`, and `--no-ntfy` as with the forward pipeline. Then use `prepare_artifacts.py <system> without_sensitivity <run>`. Keep the original paired seeds and verify the saved data/config identities before interpreting an ablation.

## CSTR and grid

CSTR writes its checkpoint to `outputs/cstr/forward/best_model.pt`; its data cache is under the same run. The grid uses `full/methods/parafdeonet/seed_<seed>/best_model.pt` and preserves the full dataset for the fresh-history overlap audit. These applications accept explicit run/checkpoint paths and do not use `prepare_artifacts.py`.

## Archived data

- `results/paper/source_data/`: figure sources and forward/inverse metrics.
- `results/paper/cstr/`: forward summaries and the 20-event industrial results.
- `results/paper/sensitivity/`: independently computed derivative checks and per-case summaries.
- `results/paper/smart_grid/`: aggregate labels from the forward training split and saved training-only GBT tuning choices.
- `results/paper/figures/`: figures used by the supplied manuscript sources.

The GBT label archive contains aggregate synthetic outcomes, not model weights. Its sum of history counts is 24,576. `refit_grid_gbt.py` can fit and evaluate the published fixed configuration without any neural-network checkpoint. The historical hyperparameter search is represented by its archived choices and results; it is not rerun by that utility.
